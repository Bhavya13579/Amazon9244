# Amazon 
Built as a portfolio-grade analytics project to showcase production-level SQL and Python skills

Amazon-Style Retail Analytics | SQL & Python
Designed a simplified e-commerce data model and analytics workflow that closely reflects the economic structure described in Amazon’s 10-K, including product category mix, GMV-based revenue logic, Prime vs non-Prime behavior, and order fulfillment outcomes. Generated realistic retail data in Python and used advanced SQL (joins, window functions, cohort and revenue analysis) to extract insights on growth drivers, customer value, and category performance, demonstrating how large-scale retail businesses are analyzed in practice.
